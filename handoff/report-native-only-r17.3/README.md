# Native-only Demand Review preview R17.3

This is a **page-one design and behavior preview**, following the explicit
23 October instruction to use no custom visuals and assess native behavior
before deciding how to restore other functionality. It is not R16.6 parity
or a qualified production replacement.

Start with [the receiving steps](OPEN%20FIRST%20-%20NATIVE%20ONLY.txt).

| Copy | Data connection | Purpose |
|---|---|---|
| `candidate/ForecastMaster Native Only R17.3 SAMPLE.zip` | Local fabricated calculated tables; no Fabric connection | Open on a laptop without company access to inspect the same native layout |
| `candidate/ForecastMaster Native Only R17.3 TEST.zip` | Existing `ForecastMaster Native OneLake R17.1 - TEST` | Check the actual company queries on the connected laptop |

Both contain only built-in `slicer`, `lineChart`, `pivotTable`, `tableEx`,
`textbox`, and `actionButton` visuals. The packaged reports have no custom
visual registrations, hidden fallback pages, JavaScript or `.pbiviz` files.
A JSON color/font theme is ordinary native formatting.

No setup cell, model change, refresh, connection change or publication is
part of this handoff. The TEST report keeps the existing TEST binding exactly.
Previous packages and the published R16.6 report are preserved.

## Corrections made in the report definition

- The frozen R17.2 headline's duplicate native `Label` query references are
  reproduced by a regression check and replaced with distinct field names.
- Every semantic numeric formatting literal is typed. Slicer item fonts use
  the native `textSize` property, rather than the unsupported `fontSize` key.
- Dropdowns reserve 88 logical pixels, including their native header and
  explicit padding. The Between date slicer reserves 128 pixels and disables
  responsive collapse. Rectangles and content bands do not overlap.
- Text headings contain native paragraph content, rather than an empty
  textbox whose container title was used as its contents.
- The line chart uses monthly categories, straight segments, visible monthly
  markers and the supported native `zoom` object. Its axis disables extra
  display-unit scaling while retaining the measure's dynamic percentage,
  currency and k/m formats. The autogenerated subtitle is disabled.
- The headline and executive matrices omit the redundant source-scanning
  visual measure filter. This preview fixes Automatic ADS in the physical
  page filters; the original DAX source/cohort and missing-data guards still
  apply. The matrices group by the requested business rows and periods,
  without redundant cycle/scenario levels. Conditional color recomputation
  is absent from the preview. **Company performance is still unverified.**
- The file section is a native metadata table with filename, driver and saved
  cutoffs, rather than one long path/timestamp identity dropdown. Its scope is
  the current Affiliate and demand cycle; it does not silently override sources.

## Deliberate limits for this first native preview

| Capability | Preview behavior |
|---|---|
| Demand Review | Included; one Affiliate, cycle and measure at a time |
| Growth drivers / forecast tiers | Native multi-select dropdowns with availability filters |
| Review summary periods | FY/YTD/YTG/H1/H2 and multiple periods retained |
| 6M / 12M / 24M | Native headline selector and multi-select trend comparisons retained |
| Plan source | Automatic ADS only; manual file/version overrides deferred |
| Currency | Source currency only; USD conversion/rate editing deferred |
| S&OP | Deferred until Demand Review has passed native receiving checks |
| Drag ordering, custom pins, linked hover, automatic Hide reflow | Absent; assess native alternatives after this preview |
| R16.6 fallback and refresh-action page | Absent from this candidate; use the existing published report for those functions |
| Export, Focus mode and page/chart zoom | Native definitions/menu retained; verify the actual receiving behavior |

The strict available-member, ratio, missing-versus-zero and source guards are
not rewritten to make visuals load. No company amounts or credentials are
included. The SAMPLE uses the frozen synthetic R17.2 fixture and unchanged
49 native measures; source tables are all fabricated calculated partitions.

## Evidence and outstanding gates

[VALIDATION.json](VALIDATION.json) records structural regressions, exact ZIP
hashes, source preservation and Microsoft schema validation. These checks
**do not prove native rendering, interaction or company query performance**.
The Windows UI bridge failed before selecting a window because its sandbox
metadata rejected the WSL working-directory URI. A standalone engine launch
also exited before providing an endpoint. Neither is recorded as acceptance.

The user's supplied `CouldNotResolveSemanticQueryDefinition` details confirm
a query-definition failure. They do not distinguish memory exhaustion from a
timeout or prove the executive matrix's remaining performance. The first
receiving check is whether that matrix now executes; if not, capture its full
error and Performance Analyzer query before changing capacity or amount logic.

Technical authoring references are Microsoft's [slicer sizing and properties](https://github.com/microsoft/skills-for-fabric/blob/main/skills/powerbi-report-cli/references/authoring/slicers.md),
[native projection uniqueness](https://github.com/microsoft/skills-for-fabric/blob/main/skills/powerbi-report-cli/references/authoring/expressions.md),

and the published PBIR schemas. Unsupported formatting can pass the permissive
object schema; schema success is explicitly separate from Desktop acceptance.
