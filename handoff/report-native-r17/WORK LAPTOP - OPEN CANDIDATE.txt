The candidate is now in Coordination. No private file transfer or builder is
needed. This is a thin report: it retains the company-model connection, but
contains no cached sales model and requires your normal company sign-in.

1. Open forecastmaster-coordination in VS Code, then Terminal > New Terminal.
2. From that repository terminal, run:

   git pull --ff-only
   explorer.exe .\handoff\report-native-r17\candidate

3. Right-click ForecastMaster Native Review R17 - Candidate.zip > Extract All.
   Use a NEW Desktop folder named ForecastMaster Native Review R17.
   Leave R16.6 and the published ForecastMaster Review unchanged.
4. Use the NEW small probe in the repository, not the old combined installer
   inside the ZIP. From the same PowerShell terminal, run:

   Get-Content -Raw -Encoding UTF8 ".\handoff\report-native-r17\PROBE ONLY - READABLE.py" | Set-Clipboard

   code cell at the bottom. Keep existing setup cells unchanged.
6. Click inside the new code editor and press Ctrl+V. Leave MODE = "PROBE".
   Run ONLY that new cell using its play button. Do not use Run all.
7. Copy its complete short output into this chat. It reads model metadata only
   and identifies whether the current native source adapter is compatible.
